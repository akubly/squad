## Findings

### Directive 1 — Ambient module export default canonical form

**Status:** REFERENCE ESTABLISHED  
**Scope:** packages/squad-cli/src/types/qrcode-terminal.d.ts

Current form:
```typescript
declare module 'qrcode-terminal' {
  export default { generate }
}
```

Canonical form (for future use):
```typescript
declare module 'qrcode-terminal' {
  const _default: {
    generate(text: string, opts?: QrcodeOptions, cb?: Callback): void;
  };
  export default _default;
}
```

**Rationale:** The explicit const _default shape makes the exported type unambiguous. Prevents confusion about whether an expression or type is being exported.

**Applies to:** All future ambient module declarations in this codebase.

### Nit 1 — qrcode-terminal.d.ts non-idiomatic form

**Finding:** The qrcode-terminal ambient declaration uses `export default { generate }` (object literal shorthand), which is syntactically accepted by tsc but non-idiomatic. TypeScript's module augmentation docs show the canonical const _default pattern.

**Impact:** None on this piece. tsc validates the type correctly. Recommended for normalization in a future touch of this file (piece 25+).

### Nit 2 — resolveSquadDir lacks injectable env seam

**Finding:** `squad-resolver.ts` exports `resolveSquadDir(cwd: string): string | null` with hardcoded `process.env` access. This prevents env injection in unit tests.

**Contradiction:** Piece 23 itself ships D-13 (Options-Bag Test Seam Convention), which mandates injectable options for all CLI test seams. `resolveSquadDir` contradicts the same-piece convention it documents.

**Recommended fix (for piece 25):**
```typescript
export function resolveSquadDir(
  cwd: string,
  env: NodeJS.ProcessEnv = process.env
): string | null {
  return resolveSquadV2({ cwd, env })?.path ?? null;
}
```

**Backward compatibility:** Full. Optional parameter with default value. No semver bump required.

**Why flagged for piece 25:** The `resolveSquad` v1/v2 renaming is already on the piece-25 roadmap. Adding the env seam should land with that renaming to minimize churn.
