### Key Learnings Captured

**For Teams Writing CLI Subprocess Tests:**
- `SQUAD_CALLSIGN=''` (empty string) causes resolver to throw, not return null
- Tests needing null resolution must omit `SQUAD_CALLSIGN` from subprocess env entirely
- Use `runCliShort` helper with explicit env stripping for parent-env contamination
- `void runRC(...)` in unit tests prevents hanging on end-of-function promise
