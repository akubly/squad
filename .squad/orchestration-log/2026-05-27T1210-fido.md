## Behavioral Assessment

### .git-marker divergence

The new SDK resolver (resolution-v2.ts:69–80) requires a `.git` marker. Without it, `findGitRoot()` returns null and local `.squad/` detection (Step 2) is skipped. The old economy.ts manual walk checked `.squad/` existence directly. This is a real behavioral regression for:
- Downloaded zips (no .git/)
- Non-git directories
- Shallow clones without .git/ at root

**Risk assessment:** Bounded. All callers handle null via fatal() — failure mode is graceful. No production squad project lacks .git/. The untested assumption should be documented for the next maintainer.
